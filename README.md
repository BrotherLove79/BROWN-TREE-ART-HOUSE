# Brown Tree Art House

A nonprofit arts and community organization that creates welcoming spaces for creativity, mentorship, and belonging.

## Local preview

Open `index.html` directly in a browser, or serve the site locally with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive nonprofit landing page
- Program and impact sections
- Volunteer and contact forms with front-end success states
- Donation panel with selectable amount buttons
- Modern visual identity designed for community arts work
